# Data files

- `live-intel.json`: cards shown in Live Intel Monitor.
- `source-tiers.json`: automatic domain/source tier mapping.
- `feeds.json`: RSS feeds used by the GitHub Action refresher.

Manual leak/social content is kept in `index.html` so you control what appears publicly.

- `leak-images.json` — curated visual/source database used by the V11 gallery and image-cache workflow. `confidence` is an editorial S.A.L.E.M. score, not a factual probability.
